# CareerIQ Portfolio Review

## One-Line Summary

CareerIQ is an AI-powered job market intelligence platform that compares resumes against job posting data and recommends career improvements across technical and non-technical roles.

## What This Project Demonstrates

### Data Analytics

- Job market dashboard
- Skill demand analysis
- Hiring city analysis
- Experience requirement analysis
- Role family analysis across analytics, software, project management, HR, sales, marketing, and operations

### SQL

- Normalized SQLite schema
- Many-to-many job and skill modeling
- Dashboard aggregation queries
- Candidate analysis persistence

### Python

- Modular package structure
- PDF extraction
- Data loading
- Resume parsing
- Scoring engine
- Roadmap generation

### Data Engineering

- CSV ingestion
- Data cleaning
- Skill normalization
- SQLite loading
- Repeatable loader script

### NLP and Text Processing

- Resume text extraction
- Rule-based skill detection
- Section extraction for education, certifications, experience, and projects
- Candidate name extraction for personalized greetings

### Product Thinking

- Target users are clearly defined
- Scores are explainable
- Recommendations are actionable
- Version 1 is scoped realistically
- The app handles extraction failure states with clear user guidance

### Full-Stack Python

- Streamlit frontend
- Python backend logic
- SQLite persistence
- Unit tests
- Deployment readiness

## Suggested Resume Bullet

Built CareerIQ, a Streamlit and Python career intelligence platform that parses PDF resumes, loads multi-role job market data into SQLite, analyzes skill gaps, calculates explainable employability scores, and generates personalized career roadmaps.

## Suggested GitHub Description

AI-powered job market intelligence platform for resume parsing, skill gap analysis, employability scoring, and career roadmap generation across technical and non-technical roles using Python, Streamlit, SQLite, Pandas, and pdfplumber.

## Suggested LinkedIn Post

I built CareerIQ, a portfolio project that helps entry-level tech professionals understand how competitive they are in the job market.

The app lets users upload a resume, extracts resume text, detects career signals, compares skills against a Canadian job posting dataset, calculates explainable scores, and recommends a learning roadmap.

Tech stack: Python, Streamlit, SQLite, Pandas, pdfplumber, SQL, and rule-based NLP.

This project demonstrates data analytics, SQL, data engineering, NLP, BI dashboarding, and product thinking in one end-to-end workflow.
